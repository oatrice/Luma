## Recommendations (Non-blocking)

### 1. Add more logging for debugging
```python
# In resolve_project_target_dir, consider adding debug logging:
logger.debug(f"Resolved target_dir: {target_dir} (original: {project_path})")
```

### 2. Consider caching the worktree path
If `resolve_project_target_dir` is called multiple times in one session, caching could help performance (though not critical).

### 3. Add environment variable override for worktree
Some users might want to force a specific path via env var:
```python
LUMA_FORCE_WORKTREE_PATH = os.getenv("LUMA_FORCE_WORKTREE_PATH")
```
