# Manual Verification Guide: Worktree Support for Select Issue & Code Review

> **Feature**: Worktree Path Resolution for Luma CLI Actions  
> **Issues**: #64, #70  
> **Date**: 2026-04-10

---

## Prerequisites

- Git worktree ที่ถูกต้อง (เช่น `/Users/oatrice/Software-projects/Luma-worktrees/clone`)
- Luma CLI พร้อมใช้งาน
- Project configured ใน `.luma_global.json`

---

## Verification Steps

### Step 1: Verify Worktree Detection

**Action:**
```bash
cd /path/to/your/worktree
python3 main.py
```

**Expected Result:**
- Luma ตรวจจับ worktree และแสดงข้อความ `🌿 Worktree detected: Using {path}`

---

### Step 2: Test Select Issue from Worktree

**Action:**
1. เปิด Luma menu: `python3 main.py`
2. เลือก `[2] 📥 Select Issue (from Kanban)`
3. เลือก issue ใดก็ได้
4. ตรวจสอบว่า branch ถูกสร้างใน worktree

**Expected Result:**
```bash
# ใน terminal
$ git branch
* fix/issue-XX-worktree    # branch ถูกสร้างใน worktree
```

**Verification:**
```bash
git rev-parse --show-toplevel
# ควรแสดง path ของ worktree ไม่ใช่ main repo
```

---

### Step 3: Test Generated Files Location

**Action:**
1. ทำ Step 2 ให้เสร็จ (เลือก issue)
2. ตรวจสอบไฟล์ที่สร้าง

**Expected Result:**
```bash
ls docs/features/{issue_number}_*/
# ควรมี: spec.md, plan.md, sbe.md
```

**Verification:**
```bash
# ตรวจสอบว่าไฟล์อยู่ใน worktree ไม่ใช่ main repo
realpath docs/features/{issue_number}_*/spec.md
# ควรขึ้นต้นด้วย /path/to/worktree/
```

---

### Step 4: Test Code Review from Worktree

**Action:**
1. สร้างไฟล์ใหม่ใน worktree:
```bash
echo "# Test change" >> test_file.md
git add test_file.md
```

2. เปิด Luma menu: `python3 main.py`
3. เลือก `[6] 🧐 Code Review (Local)`
4. ตรวจสอบ output

**Expected Result:**
```
🚀 Reviewing clone...
   📡 Configuring git scope (origin/main...HEAD)...
   🔎 Found X changed files in clone.
```

**Verification:**
```bash
ls code_review.md
# ไฟล์ควรอยู่ใน worktree directory
realpath code_review.md
```

---

### Step 5: Test Update Docs from Worktree

**Action:**
1. แก้ไข CHANGELOG.md ใน worktree
2. เปิด Luma menu: `python3 main.py`
3. เลือก `[7] 📝 Update Docs`

**Expected Result:**
- Luma อ่าน CHANGELOG.md จาก worktree
- ไฟล์ถูกอัปเดตใน worktree

**Verification:**
```bash
git diff CHANGELOG.md
# ควรเห็นการเปลี่ยนแปลงจาก Luma
```

---

### Step 6: Test Headless Mode from Worktree

**Action:**
```bash
python3 main.py --project 12 --issue 64 --action bootstrap
```

**Expected Result:**
- Git operations ทำงานใน worktree
- ไฟล์ถูกสร้างใน worktree

---

### Step 7: Regression Test - Main Repo Still Works

**Action:**

```bash
cd /path/to/main/repo

```

**Expected Result:**
- Luma ทำงานปกติใน main repo (ไม่ detect worktree)
- ไม่มีข้อความ `🌿 Worktree detected`

## Troubleshooting

**ปัญหา:** Luma ไม่ detect worktree  
**แก้ไข:** ตรวจสอบว่าอยู่ใน git worktree จริง:
```bash
git rev-parse --is-inside-work-tree
git rev-parse --show-toplevel
```

**ปัญหา:** ไฟล์ไปอยู่ main repo  
**แก้ไข:** ตรวจสอบ `resolve_project_target_dir()` ใน `luma_core/tools.py`
