## Summary

This Pull Request introduces automated `.gitignore` management for AI agent ephemeral artifacts, refactors the AI agent artifact lifecycle, and updates project documentation to reflect recent architecture decisions.

## Changes

- **Automated `.gitignore` Management**: Added a mechanism to automatically inject and maintain `.gitignore` rules for AI ephemeral artifacts (e.g., `.agents/` and `docs/features/`). This feature is controlled by a new `AUTO_UPDATE_GITIGNORE` configuration toggle, allowing users to enable or disable it globally or locally via `.luma_dev.json`.
- **Artifact Lifecycle Refactoring**: Refactored the lifecycle of AI agent artifacts to ensure consistency and better separation of concerns.
- **Documentation Updates**: Updated Architecture Decision Record (ADR) 001 to accurately reflect the agnostic VCS CLI integration.
- **Unit Testing**: Added comprehensive unit tests for the new `ensure_artifact_gitignore` functionality to ensure it correctly honors global and local configuration overrides.

## Impact

- Prevents accidental commits of ephemeral AI-generated files and artifacts, keeping the repository clean.
- Improves flexibility by allowing developers to opt-out of automated `.gitignore` updates locally if needed.
- Aligns architecture documentation with the current agnostic VCS CLI implementation.
